# Imsha Café

A responsive, single-page café website with a menu, order calculator, reservation form and interactive features. Built to practise core web development skills using HTML5, CSS3 and vanilla JavaScript.

## 🛠️ Tech Stack

- HTML5 (semantic elements, forms, tables, lists)
- CSS3 (Flexbox, media queries, responsive design, dark mode)
- JavaScript (DOM manipulation, event handling)

## ✨ Features

- Light/Dark mode toggle
- Live Open/Closed status based on the current time
- Menu cards and price table with row highlighting
- Category filter (All, Drinks, Pastries)
- Order total calculator using checkboxes
- Reservation form with validation and age-based discount message
- "Read More" toggle in the About section
- Live character counter for the special request box

## 🚀 How to Run the Project

You can view the live project directly here: [https://afshayasin17-blip.github.io/Imsha-Cafe/](https://afshayasin17-blip.github.io/Imsha-Cafe/)

Alternatively, to run it locally:
1. Clone or download this repository.
2. Open the project folder and double-click the `index.html` file.
3. The assignment will open automatically in your default web browser.



## 📁 Project Files

- `index.html` - page structure
- `styles.css` - styling and responsive layout
